# 🏠 Rental Scam Detection System

An AI/ML-based web application that detects potentially fraudulent rental listings using Machine Learning.

## 📌 Project Overview

Rental scams are fraudulent property listings created to mislead potential tenants. This project analyzes rental listing and advertiser-related features to identify whether a listing is likely to be legitimate or potentially fraudulent.

The system uses a Random Forest Machine Learning model and provides predictions through an interactive Streamlit web interface.

## 🎯 Objectives

- Detect potentially fraudulent rental listings
- Analyze patterns associated with rental scams
- Apply Data Science techniques for data cleaning and analysis
- Compare multiple Machine Learning algorithms
- Build an interactive prediction interface
- Deploy the ML model as a live web application
