
# Rental Scam Detection System

An AI/ML based system that detects potentially fraudulent rental listings using Machine Learning.

## Features

- Rental listing scam prediction
- Random Forest classification
- Scam probability
- Data preprocessing
- Feature engineering
- Streamlit GUI

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Streamlit

## Machine Learning Model

Random Forest Classifier
