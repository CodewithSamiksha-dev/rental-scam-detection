# Rental Scam Detection System

An AI/ML-based web application for detecting potentially fraudulent rental listings using machine learning and data analysis.

## Project Overview

Rental scams involve fraudulent property listings designed to deceive potential tenants. This project analyzes rental listing and advertiser-related information to identify patterns associated with fraudulent listings.

The system uses a Random Forest classification model and provides predictions through an interactive Streamlit web application.

## Objectives

- Detect potentially fraudulent rental listings
- Analyze patterns associated with rental scams
- Perform data cleaning and exploratory data analysis
- Apply feature engineering and data preprocessing
- Compare multiple machine learning algorithms
- Build an interactive prediction interface
- Deploy the trained model as a web application
